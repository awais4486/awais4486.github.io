# Portfolio

## Run locally
Open a terminal in this folder and run one of:

    python -m http.server 3000        # Python (any OS; use python3 on Mac/Linux)
    npx serve -l 3000                 # Node

Then open http://localhost:3000

## Change content
Edit `data.js` only. Put screenshots in `assets/screenshots/` and your photo at `assets/me.jpg`.
